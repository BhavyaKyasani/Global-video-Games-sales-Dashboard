🎮 Global Video Game Sales Dashboard – Power BI
📌 Overview
This project is an interactive Global Video Game Sales Dashboard built using Power BI. It analyzes video game sales across different regions, platforms, genres, and years to identify trends and top-performing games.

📊 Features
Total Global, NA, EU, and JP sales overview
Top 10 best-selling video games
Sales analysis by platform and genre
Year-wise sales trend visualization
Interactive filters for better analysis

🛠 Tools Used
Power BI
DAX
Data Visualization

📂 Files
.pbix file – Power BI dashboard
vgsales.csv – Dataset

🎯 Purpose
This project demonstrates my skills in data analysis, visualization, and dashboard creation using Power BI.
